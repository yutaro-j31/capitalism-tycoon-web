### 状態を作った場面（4.の許可範囲）

1. **E 資金繰り危機**：エンジンの `companyCash` を負の値に書き換えた。`tests/ui3-crisis-webkit-test.js` と同じ手順（`finance.defaultFinanceState` で財務状態を作り直し、`playerCrisis.evaluate`）。この手順の前に、財務状態を作り直さずに現金だけ書き換えた2回は、会計の貸借一致検査（P2-CLOSE-BS-IDENTITY）が失敗した。これは**私の状態作成が原因**で、不具合として数えていない。
