# 実機の確認手順書（UI v3・iPhone Safari）

オーナーが実機で、v3 を最初から最後まで遊んで確かめるための手順です。自動の検査（Chromium・WebKit）では確かめられない、実機でしか分からないことを確かめます。

## 準備

- iPhone の Safari で、アドレスの末尾に `?ui=3` を付けて開く（例：`…/index.html?ui=3`）。一度付ければ、その端末では v3 のままです（現行の画面に戻すときは、末尾を `?ui=2` にして開きます）。
- 前の保存が残っていると、創業画面が出ません。出ないときは、設定の「最初からやり直す」を押す前に、**保存を消してよいか**確かめてください。
- 画面を縦向きにし、文字サイズは標準のままにします。
- 確認中に「おかしい」と思ったら、その手順の番号と、画面のスクリーンショットを残してください。

## 見方

- **押す場所**：画面のどこを押すか。
- **確かめること**：押した結果、何が起きていればよいか。起きていなければ失敗です。

## 手順

| # | 押す場所 | 確かめること |
| --- | --- | --- |
| 1 | 創業画面で会社名などを入れ、下端の「創業する」 | 1画面に収まり、ボタンが下端に固定され、キーボードが出てもボタンが隠れない。創業するとホームの先頭から始まる。 |
| 2 | ホーム → 下の「マップ」 | 地図が出る。指1本で動かせ、2本指で拡大縮小でき、縦のスワイプでページが動かない。 |
| 3 | 地図の空き物件のピン → 「出店する」 | 出店のシートが出る。費用・出店後の現金が出ている。 |
| 4 | 出店の確認 →（名前を入れる画面が出たら）名前を入れて「決定する」 | 名前を入れる画面が現行ではなく v3 のシートで出る。キーボードが出ても「決定する」が隠れない。出店後、店舗数が1店になる。 |
| 5 | 下の「事業」→ 店舗の行 | 店舗のシートが出る。コンセプト変更・設備・改装は、費用が出る確認シートを通る。「やめる」では何も変わらない。 |
| 6 | 「事業」→ 上のチップ「本社」→ 部門の行（例：経理部門）→「設置する」 | 設置費・週の費用・実行後の現金が出る。実行すると、その部門の行が「設置済み」になり、人員が出る。 |
| 7 | 同じ部門の行 →「1人採用する」 | 採用費30万円が出る。実行後、人員が1名増える。 |
| 8 | 下の「投資」→ 株式 → 銘柄の行 →「買う」 | 株数を入れる金額入力シートが出る（現行のダイアログではない）。入れた株数で、実行後の現金が出る。 |
| 9 | 「会社」→「資金調達」→「借りる」 | 金額入力シートが出る。借入後の残高・残りの借入余力が出る。実行後、借入残高が増える。 |
| 10 | 画面の下の「進める」と「4週」 | 週が進み、週間レポートが出る。画面下の部品と重ならない。 |
| 11 | 現金が足りなくなるまで 10 を繰り返す（出店を重ねる、借入を返さない、など） | 画面上部に「資金繰り」の注意の札が出る。どの画面でも出ている。 |
| 12 | 注意の札 | 資金繰りの対応シートが出る。数字4つ（会社現金・不足額・猶予期間・回復確認）と、創業者資金の注入・緊急融資などの行が出る。シートの中でスクロールできる。 |
| 13 | 対応シートで「創業者資金を注入」（または緊急融資） | 金額入力シート（または確認シート）が出る。実行後、会社現金が増え、不足額が減る。 |
| 14 | 対応が足りれば、さらに「進める」 | 「回復確認」の数字が進み、回復すると札が消える。 |
| 15 | 対応をせず、猶予が尽きるまで「進める」 | 倒産して、ゲームオーバー画面になる。理由が出る。 |
| 16 | ゲームオーバー画面の「最初からやり直す」 | 確認シートが出る。実行すると創業画面に戻る。ほかの行（スロットから読み込む・結果カードの保存・JSON）も、押すと何かが起きる。 |

## そのほか（時間があれば）

| # | 押す場所 | 確かめること |
| --- | --- | --- |
| A | 「事業」→ 「ほかの詳細（現行の画面）」の行 | 現行の画面が開き、画面の下に「‹ 新しい画面に戻る」が出る。押すと、同じ画面が v3 で出る。 |
| B | 同じ画面で、何かのダイアログを開く | ダイアログが開いている間は「‹ 新しい画面に戻る」が隠れる。 |
| C | 本社カード（「事業」→「本社」）で、本社名が長い場合 | 本社名と「社員数」が重ならない。（重なって見える既知の件です。重なれば報告してください。） |
| D | 上場後、「投資」→ 株式 →「株主還元」 | 配当・自社株買いの行が出る。金額入力シートで、予定総額が出る。（上場までの道のりが長いので、時間があれば） |

## 倒産まで届かないとき

手元の検査では、倒産に至る遊び方を通しては確かめていません（倒産の画面は、状態を作って確かめています）。11〜15 で倒産まで届かない場合は、そこまでの手順と、その時点のスクリーンショットを報告してください。実際の遊びで倒産までにかかる週数は、まだ分かっていません。

## 報告の書き方

- 失敗した手順の番号
- 機種と iOS の版
- 押したこと、起きたこと、起きるはずだったこと（1行ずつ）
- スクリーンショット
