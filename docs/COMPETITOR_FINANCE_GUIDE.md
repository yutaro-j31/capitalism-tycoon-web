# Phase 5A Competitor Guide

Phase 5A はラーメン（businessID: `ramen`）だけに決定論的な競合企業 AI を追加する。正本は `competitorStates[]` で、各社は `marketPresence[]` に地域別の店舗網、能力、価格、品質、ブランド、売上、利益を保持する。対象外業種は従来の静的 `competitors` と `competitorOffers()` を使う。

主要戦略は低価格型、品質型、ブランド型、利便性型、バランス型。価格は 4 週、広告・品質・能力・撤退は主に 13 週周期で判断し、行動は `competitorActions[]` に理由つきで保存する。AI はプレイヤー価格、公開店舗数、前週市場シェアなどの公開情報だけを `lastKnownPlayerSignals` に保持し、会社現金・在庫・原価など非公開情報は参照しない。

財務は簡易週次で、売上、変動費、固定費、広告費、R&D、能力維持費、利息から利益を算出する。借入は現金不足時の限定措置で利益には計上しない。撤退は連続赤字・低シェア・低稼働を要求し、1 週赤字だけでは倒産しない。
