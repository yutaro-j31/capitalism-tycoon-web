# Stock chart guide

## 保存形式

各銘柄 `g.market[]` に `priceHistory` を持たせる。形式は `{ week, price }` の配列。

## 追加タイミング

履歴は `updateMarket()` の株価更新後に追加する。1回の週送りにつき各銘柄1件だけ追加し、同じ週の重複は正規化で排除する。株式画面表示、再読み込み、売買、期間変更では追加しない。

## 履歴上限

直近260週を保持する。非有限、0以下の価格は保存しない。

## 旧セーブ

`saveVersion: 2` 以前、または数値配列の `priceHistory` は `saveVersion: 3` へのマイグレーションで `{ week, price }` に変換する。履歴がない銘柄は有効な `previous` を前週、`price` を現在週として最小履歴を作る。架空の長期履歴は生成しない。

## 選択銘柄UI

株式一覧の行タップまたは「詳細」ボタンで選択する。一時UI状態 `ui.selectedStockId` に保持し、セーブには保存しない。選択候補は、現在表示中の選択銘柄、保有銘柄、お気に入り、先頭銘柄の順に選ぶ。

## 期間切替

`ui.stockChartRange` で13週、26週、52週、全期間を切り替える。初期値は52週。期間変更はセーブしない。

## Canvas描画

外部ライブラリは使わず、既存 `drawLine()` をdevicePixelRatio対応に拡張し、`drawStockChart()` から呼ぶ。数値フォールバックに開始価格、最新価格、高値、安値、騰落率、上昇/下落矢印を表示する。

## iPhone Safari対応

Canvas幅は `clientWidth`、親要素幅、固定フォールバック幅の順で取得する。毎回 `canvas.width/height` を設定し、可能なら `setTransform(dpr, 0, 0, dpr, 0, 0)` を使ってscale累積を避ける。

## 指標追加方法

詳細カードの表示指標は `renderStockDetail()` に追加する。存在しないデータは生成せず `—` を表示する。

## テスト

`npm run test:stock` で履歴、旧セーブ移行、UI静的要素、固定シードの基本回帰を確認する。`npm test` にも含まれる。

## 変更禁止範囲

株価変動率、ボラティリティ、景気連動、業績連動、配当、PER/PBR、時価総額、売買価格、手数料、保有株数、平均取得価格、乱数呼び出し順序は変更しない。
