## 2. 現在のゲーム仕様（機能一覧）

### 基本
- 1週ずつ進行（停止・3段階の速度・+1週）。日付は2027年1月4日開始。
- 決定論：シード付き乱数（mulberry32）のみ使用。`Math.random()` は不使用。UI表示は乱数を消費しない。
- セーブ：ブラウザの localStorage（`atlas_capital_save_v1`）。端末間の引き継ぎ不可。
- 通貨：円（内部単位 1 = 1億円、株価は内部値×100円）。
- 目標：純資産1,000億円。純資産マイナスで破産。
- 画面：世界地図（ドラッグ・ピンチ・ホイール、日本ズーム）＋ タブ「市場／保有／社長／ライバル／ニュース／受信箱」。企業画面は「概要／売買／買収・提案／経営」。

### スタート画面の設定
- 会社名・社長名、難易度、機能の解放（段階的／最初から全部）、シナリオ。
- 難易度：

| | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 元手 | 50億円 | 30億円 | 20億円 |
| ライバル資金 | 0.7倍 | 標準 | 2倍 |
| ライバルの積極性・買付量 | 控えめ | 標準 | 強気（買付1.5倍、TOB1.6倍、対抗1.8倍） |
| 買収防衛策の発動率 | 20% | 35% | 55% |
| 追証ライン | 80% | 70% | 60% |

- シナリオ：標準／バブル崩壊直後（株価3割安・景気後退・低金利）／超円高（1ドル95円）／巨人の時代（ライバル資金2倍・各2社を支配済み）。

### 市場と企業
- 27都市（日本5：東京・大阪・名古屋・福岡・札幌、海外22）、初期59社＋新規上場（日本企業3社を含む）。すべて架空。
- 12業種。株価は理論株価（利益×業種PER×成長・景気・金利・市場心理など）へ徐々に収束し、銘柄ごとの市場心理（ムード）で長期間ずれることもある。
- 業界シェア：同業の売上シェア12%超で利益率ボーナス。
- 為替（ドル円）：海外企業の円換算利益と、日本の輸出企業（自動車・海運・テック・鉄鋼）/輸入依存企業（航空・エネルギー・食品・小売）に影響。
- 格付け（AAA〜CCC）：負債÷営業利益で決まり、借入金利に上乗せ。
- 決算：四半期ごとにアナリスト予想と実績を比較し、サプライズで株価が動く。
- イベント：経済ニュース、不祥事/躍進、MBO（非上場化）、倒産。

### 取引
- 現物売買（大口は株価を動かす、手数料0.25%）、信用買い（評価額の2倍まで、研究で2.5倍）。
- 空売り：発行済の15%まで、総額は純資産まで、貸株料年3%、配当負担、踏み上げ（純資産が空売り残高の30%未満で強制買戻し）。
- オプション：コール/プット、満期13/26週、ブラック・ショールズで価格算定、満期で自動清算。
- 名義：「本体」または支配下の「子会社」（会社の現金＋借入枠で買える）。

### 支配と買収
- 支配：本体と子会社の持分を合計したグループ持分が50%超で経営権。
- 持株ピラミッド：子会社名義で他社株を保有。保有株は会社の理論株価に反映。グループ相関図と地図の金色の線で表示。
- TOB：買付期間4週間、締切時の最高値が勝つ。ライバルの対抗TOB、ホワイトナイト（友好的合併）。LBO（自己資金35%・残り65%は対象企業の借入）。
- 株主提案（5%以上）：増配・自社株買い・不採算事業売却を要求。可決見込みは持分・割安度・評判で決まる。
- 委任状争奪戦（15%以上）：8週間後の臨時総会で勝てば1年間経営権。
- 相対取引：ライバルの持株を価格提示で直接買う（応じる／断る／逆提案）。ライバルからの買取申し入れもある。
- 合併：独禁法審査（統合後シェア25%超は事業25%売却が条件、40%超は不承認）。外資規制（航空・通信：日本企業は海外勢33%まで、海外企業は日本勢49%まで）。
- 買収防衛策（新株発行）、グリーンメール提案。

### 経営（支配企業）
- 配当性向、特別配当、自社株買い、設備投資、返済、社債発行、公募増資。
- 価格戦略（低価格：利益率−20%・成長+5%／高価格：利益率+20%・成長−5%）、価格競争で同業の利益率を削る。
- 広告キャンペーン：ブランド（成長率と高価格時の客離れに影響、放置で減衰）。
- 事業売却（15%/30%）、スピンオフ（30%を新会社として上場）。

### 社長・成長
- 役員報酬（本体純資産の0〜2%/年、税45%控除）→ 個人資産でステータス資産（スーパーカー〜プロ野球球団）。名声・称号7段階、名声は株主の支持に加算。
- 持株会社の上場・増資（資金は増えるが、あなたの取り分は希薄化）。
- ミッション（常時3つ、期限・報酬あり）、実績18種。
- 研究ツリー：4分野×4段（金融・買収・経営・情報）、研究予算（純資産の年0〜10.4%）でポイントを貯めて解放。
- 段階的な機能解放：個人投資家 → 大株主 → 経営者 → 財閥。

### 情報表示
- 秘書のメモ（市場タブ先頭、最大3件）、四半期レポート（保有タブ）、誰が何を持っているか（ライバルタブ）、純資産・為替チャート、業界シェア首位表、噂（受信箱）。

### ライバル（3人）
- ヴィクター・クレイン（強欲な乗っ取り屋）、イゾルデ・ヴァンス（割安株ハンター）、天城 剛（日本株好きの財閥系）。
- 買い集め、子会社経由の購入、TOB・対抗TOB、特別配当での吸い上げ、合併、価格戦略と広告、あなたへの相対取引の申し入れ。
- 使わない機能：株主提案・委任状争奪戦・LBO・オプション・増資・事業売却・役員報酬・研究。

## 3. 主な不具合修正・調整の記録

- 閉じたモーダルが透明なまま残り画面操作を妨げる → `[hidden]` を強制非表示に。
- TOB直後に株価がTOB価格まで跳ね上がり純資産が膨らむ → 上乗せ分の一部だけ残すよう修正。
- 単純な割安株ボットが$13〜37B（当時）まで膨張 → 銘柄ごとの市場心理を追加し、収束を緩やかに。
- 新規上場の上限が古い50社のままで上場が止まっていた → 62社に。
- 大量保有ニュースの重複、地図アニメーションの負の半径エラーを修正。
- 為替ニュースの多発（10年で約60件）→ ヒステリシスを入れて約20件に。
- 決算ニュースの多発（10年で約150件）→ 関係銘柄と超大型株に限定し約15件に。
- LBOがどの会社でも実行不能 → 自己資金35%・借入上限（営業利益8倍か資産の8割）に変更し約半数で実行可能に。
- 巨人の時代でライバルが即座に1,000億円到達 → 初期支配企業を小型株に限定・資金2倍に。
- TOB成立後に防衛策の新株発行で目標未達になる → TOB決済中は防衛策を発動しない。
- ホワイトナイト合併のプレミアム表示がTOB中の株価基準で小さく見える → TOB前株価基準に。
- 「YTR」名義が個人か会社か分かりにくい → 「〇〇本体」「子会社 〇〇」に統一。
- 同じ持分が2か所に出て二重保有に見える → 「支配している会社」に本体＋子会社経由の内訳表示。
- 子会社保有株の損益が不明 → 全保有者の取得原価を記録（スピンオフ・合併でも引き継ぎ）。
- 価格戦略で高価格だけが圧倒的に有利 → 効果を自社の利益率比例に変更し、成長期待を理論株価に反映。

## 4. 検証方法と最新の結果

- ヘッドレスブラウザ（Playwright/Chromium）で、PC幅（1366px）とiPhone 13幅の両方を操作・スクリーンショット確認。横はみ出し・コンソールエラーなし。
- 長期シミュレーション（各難易度×複数シード×10年）：数値の破損（NaN/負の現金/発行済超過）なし、支配判定の矛盾なし。
- 決定論：同一シードを2回実行して価格・TOB・為替・噂・ミッションまで一致。
- 単純な割安株ボットの1,000億円到達年数（直近）：やさしい7.5〜9.4年／ふつう8.3〜14.5年／むずかしい11.1〜14.4年（乱数の並びが変わると幅が出る）。
- 新機能の個別確認例：
  - 相対取引の応諾率：+0%ほぼ拒否、+15%逆提案中心、+30%約6割成立、+50%約8割成立。
  - 価格戦略（6年後）：高価格＝現金最大・企業価値の伸び最小、低価格＝売上と企業価値が最大・現金最小、標準＝中間。
  - プレイヤーのTOBが対抗される割合：ふつう約28%、むずかしい約50%。

## 5.4 P0・Phase 1（引継ぎ資料 2026-11-13 に基づく）
- **P0 保全**：セーブ書き込み失敗の通知、上書き前バックアップ（`atlas_capital_save_v1_bak`）、壊れたセーブからの自動復元、セーブ管理（テキストで書き出し・読み込み・バックアップに戻す）。`raider-game/tests/run.js` に回帰テストを新設（決定論・不変条件・旧セーブ見本・セーブ保全・PC/iPhone画面・市場・バランス）。
- **Phase 1 経済基盤**：
  - 市場は「地域（日本・米州・欧州/中東/アフリカ・アジア太平洋）×業種」。当初案の都市×業種では、同じ市場に2社以上いる組み合わせが0だったため変更（地域×業種なら31/59社が競合あり）。
  - 売上＝市場規模×シェア×価格水準。シェアは魅力度（基礎×ブランド×価格^−弾力性）で毎週少しずつ目標へ。中小企業の取り分あり。
  - 価格の上下幅は会社の利益率の半分（2〜8%）。固定8%だと低利益率の会社が値下げで倒れたため。
  - 費用を変動費と固定費に分離。四半期ごとに営業利益の増減を「市場規模・シェア・価格・原価率・固定費・業界シェア効果・為替」に分解（合計は完全一致）。
  - 競合（プレイヤー以外）は値下げでシェアを奪われると値下げ・広告で対抗。研究「ロイヤル顧客」は価格感応度−40%に変更。
  - 旧セーブは読み込み時に市場を逆算して作成し、売上は1円も変わらない。
  - バランス：単純ボットの1,000億円到達はPhase 1前より11〜19%早い（基準値 ±40%以内）。

## 5.5 Phase 2〜5（同日に続けて実装）
- **Phase 2 ライバル・再建・委任**：ライバルに3つの流儀（乗っ取り屋＝解体売却、再建屋＝赤字企業を立て直し、系列屋＝取引先の囲い込み）。支配企業の再建策（コスト削減・事業整理・経営刷新、効果は数か月かけて出る）。CEO採用（候補は会社ごとに決まった顔ぶれ、乱数は使わない）と経営方針（成長・均衡・現金）の委任。研究開発投資。
- **Phase 3 拡大・設立・垂直統合**：非上場会社の設立（最大5社、公正価値で評価）、別地域への子会社進出、後からの上場、清算。仕入れ先業種（例：自動車←鉄鋼）の大きな会社をグループで支配するとコストが下がる垂直統合。
- **Phase 4 金融・研究・イベント**：資金繰り危機（借換え＝金利上乗せ／増資／資産売却を選ぶ。8週放置で倒産）、格付けによる株価割引、原材料指数（航空は打撃・エネルギーは追い風）、地域ごとの需要ショック、ライバル企業の研究開発。不動産は見送り。
- **Phase 5 仕上げ**：
  - 「対応が必要」バー（ティッカー下）：受信箱の提案、資金繰り危機、TOBで対抗されている、追証・踏み上げが近い、ミッション期限。タップで該当画面へ。
  - はじめの一歩（社長タブ、6段階・小額の報酬）：初購入→5%保有→TOB→支配→経営判断→垂直統合。旧セーブは達成済みを報酬なしで記録。
  - エンドレス：1,000億円達成後も 3,000億円→1兆円→3兆円→10兆円 と次の目標を表示。
  - 長期バランス：15年で一部ライバルが5,000億円超に膨らむ原因は、テック業種の需要が年11%で複利成長し続けることだった。成長率5%超の業種は年7%ずつ成熟して鈍化（テックは15年で約7%）。8シード×3難易度でライバル最大純資産の外れ値が消え、やさしい＜ふつう＜むずかしいの順に並んだ。
  - 単純ボットの到達年数（基準値を再記録）：やさしい6.7年／ふつう9.5年／むずかしい8.5年。むずかしいのボットがふつうより早いのは、強いライバルの買い上げでボットの保有株が値上がりするため（ボットはTOB合戦などに巻き込まれない）。実プレイの難しさとは別物として記録。

## 5.6 ライバルの新しい手口と不動産（Phase 6）
- **ライバルの株主提案**：5%以上持つ会社に、流儀に合った要求（乗っ取り屋＝増配か事業売却、再建屋＝事業売却か自社株買い、系列屋＝自社株買い）。3週後の総会で採決。あなたのグループが株を持っていれば受信箱で賛成・反対を投票でき、持分がそのまま票になる。浮動株は割安な会社ほど提案に賛成しやすい。
- **ライバルの委任状争奪戦**：15%以上かつあなたより多く持つ会社で、8週後の臨時総会。勝つと1年間ライバルが取締役会を握り、その会社をライバルの流儀で経営する。あなたが委任状争奪戦で取った取締役会も奪われうる（投票で防衛）。
- **ライバルのLBO**：乗っ取り屋（ヴィクター・クレイン）は資金が足りなくても、買収先に借入を負わせるLBOでTOB・対抗TOBを出す。
- **ライバルの増資**：支配企業の借入が限界に近いと、支配が揺らがなければ公募増資、揺らぐならライバル自身への第三者割当増資。資金繰り危機の増資でも支配を守る。あなたの持分は薄まる。
- **調整**：ライバル企業の合併は1社あたり年1回まで、時価総額5,000億円以上の会社は吸収合併を続けない（増資で借入余力が戻り、1社が14社を吸収して1.5兆円に膨らむ事例があったため）。
- **不動産**：25都市に計63件（都市規模で2〜4件、名前・規模・利回りは都市名から決まり乱数を使わない）。種類はオフィスビル・商業施設・物流倉庫・賃貸住宅で、利回りと景気への感応度が違う。毎週の賃料−ローン利息が入る。ローンは評価額の50%まで（政策金利＋1.5%）。評価額は景気・金利で動き、海外物件はドル円に連動。地域ショックや不動産関連のイベントでも動く。ローンが評価額の95%を超えると競売。グループで不動産会社を支配すると仲介手数料3%→1%。ライバルも買う（系列屋は日本の物件を好む）。純資産に正味持分（評価額−ローン）を含める。「大株主」の段階で解放。
- バランス（基準値を再記録）：単純ボットの到達年数 やさしい7.9年／ふつう8.9年／むずかしい8.5年。8シード15年でライバル最大純資産の中央値は おおむね やさしい600億円・ふつう850億円・むずかしい1,050億円。

- **地図の不動産マーク**：自分の物件がある都市の右上に金色の家マーク（2件以上は「×件数」）。凡例に「あなたの不動産」を表示（持っているときだけ）。

- **地図の不動産マーク（続き）**：ライバルの物件は都市の右下に各ライバルの色の小さなひし形（1都市に最大3つ）。凡例に「ライバルの不動産」。家マークやひし形をタップすると、その都市を選んで物件一覧まで自動でスクロール（指の当たり判定は半径22px＝44px四方。都市の中心より近い位置をタップしたときだけマーク扱い）。マークは都市名ラベルより上に描く。

## 5.7 研究ツリーのバランス確認
- **方法**：①TOB・信用買い・広告・設備投資・現金回収を行うボットで、研究なし／予算3段階／各研究を最初から付与、を12シード×6年で比較。②効果を乱数なしで直接測る実験（価格・TOB応募・買付余力）。ボットの結果はシードごとのばらつきが大きく、個別研究の順位付けには使えなかった。
- **見つかった不具合**：研究完了週が0だと効果が出ない判定になっていた（`hasR` を「完了週が記録されているか」に修正）。研究予算が全研究の完了後も純資産に比例して払われ続けていた（予算3で6年に約480億円の空費）→ 今の段階で研究できる分が貯まると自動で止まる。
- **測った効果**：信用枠拡大（2億）＝買付余力+50%。買付エージェント（2億）＝+20%プレミアムでの応募が85%→100%（+30%以上では差なし）。ロイヤル顧客（6億）＝高価格にしたときの増益が営業利益の+11.5%→+20.8%、値下げ合戦への防御は+0.6ポイントのみ → 説明文を「値上げしても客が離れにくい」に修正。
- **3〜4段目の強化**（費用15〜35億に対して効果が限定的だったため）：貸株ネットワーク＝借りられる株15%→25%を追加。デリバティブ部門＝追証ラインに5%の余裕を追加。根回し＝ライバルの対抗TOB−30%を追加。M&Aアドバイザリー＝事業売却+15%→+25%。コンプライアンス体制＝摘発率も半分に。
- **予算の比較（修正後）**：1,000億円到達は 研究なし8/12、予算「少し」11/12、「普通」「多め」7/12。このボットは1〜2段目しか活かさないため、高い予算は得にならない（使う機能の研究に絞るのが有利）。
- **気づいた点（未対応）**：研究なしでも、多くの会社で「高価格」が「標準」より営業利益が高い。価格設定の釣り合いは別途見直し候補。
