# 個人トレーダーから財閥へ — 設計提案（実装前の検討）

対象：ChatGPTの構想書「個人トレーダーから世界的財閥への成長型ゲームデザイン構想」（2026-11-17）。
現在のコード（`raider-game/index.html`、約5,500行・関数約550）を確認したうえでの提案。数値はすべて仮。

---

## 結論（先に要点）

- **構想はこのゲームに合う。** すでに「会社（`S.player`＝本体）」と「社長個人（`S.pres`）」の2つの財布があり、役員報酬（税45%）・個人のベンチャー出資・高級資産は個人側で動いている。足りないのは「個人が株を売買する口座」と「会社を作る前の期間」だけ。
- **作り直しは不要。** 市場・企業・ライバル・TOB・PE・VC・本社・保存の仕組みはそのまま使える。変えるのは「誰の口座で取引するか」と「何がいつ開くか」。
- **いきなり既定を1,000万円にしない。** まず新規ゲームの選択肢（シナリオ「個人トレーダーから」）として入れ、今の「投資会社から始める」は残す。既存セーブは今のまま。
- **最大の課題は成長速度。** 上手なプレイヤーでも年45%前後（`tests/difficulty.js` の実測）。1,000万円→30億円（300倍）は複利だけだと約15年かかる。外部資金（出資・ファンド）と信用取引で「他人の資金」を使えるようにしないと序盤が長すぎる。
- **最初に作るべきは「個人と法人の口座の分離」。** ここを正しく作れば後は既存機能の解放条件の変更が中心になる。逆にここを曖昧にすると二重計上や抜け穴が出る（第2〜5回の検証で直してきた類の不具合）。

## 2. 個人と法人の分け方（最重要）

### 2-1. データの持ち方
- 株主の識別子に **個人 `U`** を新設する（今の `P`＝会社本体、`R1..`＝ライバル、`C..`＝会社、`F..`/`Q..`＝ファンド）。
  - 個人の株：`c.own.U`、取得原価：`S.pres.cost`、信用：`S.pres.loan`、空売り：`S.pres.shorts`、オプション：`S.pres.opts`、銀行：`S.pres.bank`。
  - 会社が無い間は `P` の口座を使わない（会社ができるまで `S.player` は「未設立」）。
- 売買画面の「名義」に **個人／会社／子会社** を並べる（今の名義の仕組みを拡張）。取引・余力・取得原価・税は名義ごとに計算。
- 取引の処理（`execBuy` など）はすでに「誰が買うか（k）」を受け取る形なので、`U` の現金と借入の出入り（`debit/credit` の分岐）を足せば流用できる。

### 2-2. 純資産の数え方（二重計上の防止）
- **個人純資産** ＝ 個人現金 ＋ 個人の株（時価）＋ 個人の不動産・VC・高級資産 ＋ **自社株の価値** − 個人の借入。
- **自社株の価値** ＝ 会社の純資産（いまの `grossWorth`）× 個人の持株比率。会社の現金や株を個人に直接は足さない。
- ゲームの目標・順位は **個人純資産** で測る（今は会社の純資産）。会社が外部から集めた資金は持株比率の分しか個人の価値にならない。
- 移行：既存セーブ・既存シナリオでは「個人が会社の100%を持つ」とみなせば、今の数字と一致する（互換）。

### 2-3. お金の移動は正規の取引だけ
- 個人→会社：設立時の出資、追加出資（増資の引受）、株主貸付。
- 会社→個人：役員報酬（既存・税45%）、配当（既存の配当を個人に流す）、貸付の返済、自社株の売却、清算時の分配。
- それ以外の直接移動は作らない。

## 3. 段階の設計と解放条件

| 段階 | 目安 | 開くもの | 開く条件（資産額だけにしない） |
|---|---|---|---|
| 0 個人トレーダー | 1,000万円 | 現物・ウォッチリスト・スクリーナー・ニュース | 開始時 |
| 0+ | 3,000万円〜 | 信用取引（2倍まで）・空売り | 運用52週以上 ＋ 追証0回 など |
| 1 起業 | 3,000万〜1億円 | 法人設立・本社（自宅兼事務所）・経理部 | 自分で決める（資本金の下限だけ） |
| 2 投資会社 | 1〜10億円 | 人材・部門・法人融資・外部出資・オプション | 部門・実績で開く（今の道しるべ） |
| 3 買収家 | 10〜100億円 | TOB・アクティビスト・LBO（今の段階2〜4） | 今の `FEAT_STAGE` を会社の規模で |
| 4 持株会社 | 100億〜 | PE（投資部）・VC・ファンド・IPO | 今の部門条件 |

- 既存の「段階」（`STAGES`/`FEAT_STAGE`）の前に段階0を足す形にする。上の段階は今の仕組みのまま。
- 解放に「運用実績」を使う（2-5参照）ことで、資産額だけで開く単調さを避ける。

## 4. 成長速度（1,000万円→起業→30億円）

- 上手な割安株プレイヤーで年45%前後（`tests/difficulty.js`）。複利だけだと 1,000万→1億円で約6年、→30億円で約15年。**長すぎる。**
- 小さい資金は値動きへの影響が無いので、割安株の効率は今より良い（大口ほど価格を動かす仕組みがあるため）。それでも足りない。
- 提案する加速手段（どれも「対価のある」資金。無条件の付与はしない）：
  1. **信用取引**：個人でも2倍まで（追証あり）。上手なら年60〜80%に上がるがリスクも増える。
  2. **エンジェル出資**：設立後、実績が良いと「1億円を出すので20%ください」のような提案が来る（持分の希薄化と交換）。
  3. **運用委託（小さなファンド）**：実績のある個人・会社に富裕層が資金を預け、管理報酬2%・成功報酬20%を得る。自己資金が小さくても運用額で稼げる。今のPEファンドの骨組みを流用。
- 目標の体感：個人時代2〜4年、起業後〜1億円まで2年、30億円（今の開始点）まで合計8〜10年。最終目標1,000億円まで12〜16年（今の「ふつう」10.9年より少し長い、通しの長編として）。
- 調整は `tests/difficulty.js` を個人開始に対応させて、10シード以上で測りながら行う。

## 5. 外部出資・法人融資・実績の使い道

- **運用実績**（新規）：年次リターン、最大ドローダウン、追証・強制決済の回数、運用年数、シャープレシオ（週次の値動きから計算可能）。週次の純資産履歴（`S.nwHist`）が既にあるのでそこから算出できる。
- **出資の提案**（新規・受信箱のカード）：出資額・評価額・取得比率・条件（取締役派遣、IPO期限）を提示。投資家の種類で好む指標を変える（短期で高いリターン重視／低いドローダウン重視／長い実績重視）。
- **法人融資**：今の `bankLimit`（時価担保・配当収入）を法人用にそのまま使い、運用実績と返済実績で金利と枠を補正。個人用は枠を小さく。
- **担保は時価**（第4回で整えた原則を維持）。支配プレミアムや「のれん」は担保にしない。

## 6. ヘッジファンド事業

- 今のPEファンド（`S.pe.funds`：GP/LP、管理報酬、成功報酬、投資期間）を骨組みに、**上場株を運用するファンド**を足す。
- ファンドの持株は株主 `F..` として既にある仕組み（ファンドが株主になれる）を使える。売買画面の名義にファンドを追加。
- 要素：運用資産（AUM）、管理報酬・成功報酬、ハイウォーターマーク、解約（成績が悪いと四半期ごとに一部流出）、レバレッジ上限。
- まずは「ロングのみ」と「ロング・ショート」の2種類から。マクロやイベントドリブンは後で。

## 7. 既存セーブとの互換性

- 新しいセーブ形式3：`S.mode = 'trader' | 'company'`、`S.founded`、個人口座（`own.U`・`S.pres.*`）。
- 既存セーブ（形式1・2）は `mode = 'company'`、個人が会社の100%を所有、個人口座は空、として移行。今の数字と目標は変わらない。
- チェックサム（`finSig`）に個人口座を含める。`econCheck` に「`U` の持株・借入・空売り」を追加。
- 決定論：個人開始でも乱数の消費順は「市場の進行」だけで決まるようにし、UIでは乱数を使わない（今の原則のまま）。

## 8. 起こりうる不具合・抜け穴（先に塞ぐ）

| リスク | 対策 |
|---|---|
| 会社の資産と自社株の価値を両方個人に足す（二重計上） | 個人純資産は自社株「価値」だけ。テストで恒等式を確認 |
| 設立→清算を繰り返して設立費や税を回避・増殖 | 設立費・清算費をかけ、清算は残余財産の分配だけ。自社株の評価は時価または純資産 |
| 個人の信用で会社株を買い、会社の資金で個人の借入を返す | 会社→個人の移動は報酬・配当・貸付返済だけ。株主貸付には金利と記録 |
| 個人と会社が同じ銘柄を持ち合って支配判定がずれる | 支配判定は「個人＋会社グループ」の合計（今の `groupSh` を個人込みに） |
| 出資提案を断り続けて有利な条件だけ待つ | 提案は期限付き・頻度は実績連動。断ると次の評価が下がる |
| ファンドの資金を自分の口座の利益に使う（利益相反） | ファンドと自己勘定で同じ銘柄を売買するときは制限・記録 |
| 小額での端数（1株未満）の扱い | 個人は1株単位の売買に丸める（今は連続量）。表示は既に株数 |
| 固定報酬が初期資金に比べて大きすぎる | 「はじめの一歩」の報酬（今は1〜10億円）を資産比例に。ミッション報酬の下限5億円も比例に |

## 9. ゲームを面白くする追加案

- **生活と時間の制約**：個人時代は「平日の取引時間」と「本業の給料」があり、起業すると給料が無くなる代わりに時間が増える（自動運用の幅が広がる）。
- **独立のきっかけイベント**：大きく当てた年に「独立しませんか」と元同僚や投資家から誘いが来る。
- **トラックレコードの見える化**：個人時代からの成績表（年別リターン・最大下落）をIRや出資提案の画面に出す。
- **再起**：会社が倒れても個人資産と実績（評判は減る）で再挑戦できる。今の倒産処理を「会社だけ倒れる」に分ける。
- **称号の追加**：「初めての1億円」「独立」「最初の外部出資」「AUM 100億円」など、序盤の節目。

## 11. 決めてほしいこと

1. 目標と順位は「個人純資産」で測る形でよいか（会社は手段、という整理）。
2. 個人開始は「新しいシナリオとして追加」でよいか（今の開始方法と既存セーブはそのまま）。
3. 個人の売買を1株単位に丸めるか（現実的だが、今の連続量の計算に丸めを足す必要がある）。
4. 最初の加速手段として、信用取引・エンジェル出資・運用委託のどれを優先するか（提案は「運用委託」：実績が資金になる体験が一番このゲームらしい）。
